### 1. System Health Report

**Technologies:** Bash, Linux, system utilities

A Linux system monitoring script that generates a structured health report covering system resources, processes, networking, services, and potential warnings.

**Demonstrates:**

* Bash scripting
* Linux administration
* System monitoring
* Process management
* Resource analysis
* Operational reporting

### 2. Automated Server Monitor

**Technologies:** Bash, Linux, systemd, logging

An automated server monitoring solution that checks CPU, memory, and disk utilization against configurable thresholds and records monitoring results through system logging.

**Demonstrates:**

* Bash automation
* Threshold-based monitoring
* Linux systemd
* Scheduled tasks
* Logging
* Exit codes and operational status

---

### 3. Log Archive Tool

**Technologies:** Bash, Linux, tar

A command-line tool for compressing and archiving application or system logs while maintaining an organized archive structure.

**Demonstrates:**

* Shell scripting
* Linux file management
* Log management
* Compression and archiving
* Automation

---

### 4. Nginx Log Analyser

**Technologies:** Bash, Linux, Nginx

A command-line log analysis tool that processes Nginx access logs to extract useful operational information such as request patterns, HTTP status codes, and client activity.

**Demonstrates:**

* Log analysis
* Bash and `awk`
* Linux command-line tools
* Web server operations
* Operational troubleshooting

---

### 5. PHP + MySQL Todo API

**Technologies:** PHP, MySQL, Nginx, PHP-FPM, Docker Compose

A containerized REST API backed by MySQL, with separate application, web server, and database services.

**Demonstrates:**

* Docker Compose
* Multi-container architecture
* REST APIs
* MySQL
* PHP-FPM
* Nginx
* Persistent application data

---

### 6. Python Todo API

**Technologies:** Python, Flask, Docker

A containerized Todo API packaged into a Docker image with persistent storage, health checks, a non-root application user, and custom container networking.

**Demonstrates:**

* Docker image creation
* Container security
* Persistent volumes
* Health checks
* Container networking
* Python application deployment

---

### 7. Rust + PostgreSQL Todo API

**Technologies:** Rust, Axum, SQLx, PostgreSQL, Docker Compose

A multi-container REST API built with Rust and Axum, backed by PostgreSQL and deployed using Docker Compose.

The application includes automatic database migrations, persistent PostgreSQL storage, health checks, environment-based configuration, input validation, and full CRUD functionality.

**Demonstrates:**

* Rust application deployment
* REST API architecture
* PostgreSQL
* Docker multi-stage builds
* Docker Compose
* Database migrations
* Persistent volumes
* Health checks
* Environment-based configuration
* Container orchestration
